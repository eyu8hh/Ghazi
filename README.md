# غزي — GHAZI

لعبة جماعية تُلعب بهاتف Android واحد يمرّره اللاعبون فيما بينهم، دون راوٍ خارجي: التطبيق هو الحكم والمنظّم.
الواجهة عربية فصحى بالكامل مع اتجاه RTL حقيقي. التوقيع: `@_eyu8`.

## قواعد اللعب (كما هي مطبّقة في الكود)

- عدد اللاعبين من 5 إلى 12. لا يُقبل اسم فارغ ولا مكرر (بعد حذف المسافات الزائدة).
- عدد «الدجگال»: 5–7 لاعبين = 1، 8–11 = 2، 12 = 3 (تلقائي، ويمكن ضبطه يدويًا ما دام صالحًا).
- ثلاثة أوضاع فقط:
  - **الأساسي**: الدجگال، ولد الصنتي، المحقق، كارطية.
  - **الكلاسيكي**: الأدوار الموسعة (ولد الصنتي، المحقق / الشيخ الصالح، القناص الصالح، العمدة، الولد الصالح).
  - **المخصص**: تشغيل/إيقاف الأدوار وضبط الخيارات المسموح بها.
- كشف الأدوار: لا يظهر الدور قبل أن يؤكد اللاعب أنه وحده يرى الشاشة، ثم يُخفى قبل تمرير الهاتف.
  أفراد الدجگال يرون زملاءهم (دون اسم اللاعب نفسه).
- ترتيب الليل: الدجگال ← ولد الصنتي ← المحقق ← القناص الصالح. إن كان الدور ميتًا أو غير مشارك تظهر شاشة تمويه مؤقتة لا تكشف شيئًا.
- النهار: يُعلَن ما حدث ليلًا، ثم النقاش (15 ثانية لكل لاعب حي، وينتقل التطبيق تلقائيًا إلى المتحدث التالي أو إلى التصويت عند انتهاء المؤقت)، ثم التصويت. صاحب أعلى الأصوات يدافع دقيقة (وينتقل التطبيق تلقائيًا إلى التصويت على الإقصاء عند انتهائها)، ثم يُحسم الإقصاء. التعادل يتبع الإعداد المختار: لا إقصاء، أو إعادة تصويت، أو اختيار عشوائي.
- **القناص الصالح**: طلقة واحدة، يستعملها أو يتجاوزها. إصابة دجگال تقتل الهدف ويبقى القناص حيًّا؛ إصابة لاعب من الفريق الآخر تقتله ويُقصى القناص معه.
- **الولد الصالح**: إذا أُقصي بالتصويت أو قُتل ليلًا يختار لاعبًا حيًّا يموت معه (مرة واحدة).
- **شيخ المافيا** و**مافيا التسكيت** (في الوضعين الكلاسيكي والمخصص): يشاركان فقط حين يكون عدد الدجگال اثنين فأكثر، ويأخذان من أماكن الدجگال دون تغيير حجم الفريق، والباقون دجگال عاديون.
  - شيخ المافيا صاحب الاغتيال: ما دام حيًّا فهو وحده من يختار ضحية الليل. **قاعدة غير موثقة في الأصل**: إن مات اختار الدجگال الأحياء الضحية بالتصويت كما في الأصل.
  - مافيا التسكيت يُسكت لاعبًا في نقاش النهار التالي: لا يتكلم فيه لكنه يصوّت. يُعلن اسمه صباحًا، ولا تنتقل القدرة إن مات صاحبها أو مات الهدف.
  - خيار «دجگالي واحد يجمع القدرتين» (في شاشة الأدوار): عند تفعيله مع تفعيل الدورين يحمل شيخ المافيا القدرتين ويُستعمل مكان واحد بدل اثنين، ولا يرى ذلك إلا هو في شاشة دوره. عند تعطيله يكون لكل قدرة لاعب مستقل. إن مات الشيخ ضاعت القدرتان معًا.
- **العمدة**: يعلن هويته علنًا، وبعدها يُحسب صوته بثلاثة.
- **المحقق**: يعرف انتماء اللاعب (دجگال أم صالحون) دون دوره الدقيق.
- الفوز: يفوز الدجگال عندما يساوي عددهم الأحياء عدد اللاعبين الأحياء من الفريق الآخر أو يزيد، ويفوز الفريق الآخر بإقصاء جميع الدجگال. كل لاعب حي في الفريق الفائز يحصل على **70 نقطة**.

## التشغيل والاختبار والبناء

يلزم Flutter مستقر (المستخدم في المشروع: 3.47.8).

```bash
flutter create --platforms=android --org com.eyu8 --project-name ghazi .   # مرة واحدة لتوليد مجلد android
flutter pub get
dart run flutter_launcher_icons
flutter analyze
flutter test
flutter run
flutter build apk --release        # الناتج: build/app/outputs/flutter-apk/app-release.apk
```

## البناء عبر GitHub Actions وتنزيل APK

1. ارفع المشروع إلى مستودع GitHub (راجع الأوامر أدناه).
2. يعمل الـ workflow `Build Android APK` تلقائيًا عند كل `push`، ويمكن تشغيله يدويًا من تبويب **Actions ← Build Android APK ← Run workflow**.
3. بعد نجاح التشغيل افتح صفحته ونزّل الملف `ghazi-apk` من قسم **Artifacts** (ملف ZIP بداخله `app-release.apk`).

```bash
git init
git add .
git commit -m "GHAZI: Flutter Android game"
git branch -M main
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```

> التوقيع: يُوقَّع الـ APK بمفتاح debug الافتراضي الذي تولّده Flutter، وهو صالح للتثبيت المباشر. لا تضع أي مفاتيح توقيع خاصة داخل المستودع (`*.jks` و`key.properties` مستثناة في `.gitignore`).

## بنية المشروع

- `lib/engine/`: محرك اللعبة (نماذج، إعداد الأدوار، القواعد، مراحل المباراة) منفصل عن الواجهة.
- `lib/ui/`: الشاشات. `lib/data/settings.dart`: الإعدادات والتخزين المحلي (مع ترحيل الإعدادات القديمة).
- `test/`: اختبارات المحرك والمباراة والإعدادات والواجهة.
